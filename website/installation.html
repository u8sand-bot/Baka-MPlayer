Windows

Download for Windows (64-bit)

Windows 10 or later. Unzip anywhere and run Baka MPlayer.exe; settings are kept next to it, and the player updates itself.

Also get Noto Sans font for best experience

macOS

Download for macOS (Apple Silicon)

Drag Baka MPlayer to Applications. The app is not notarized, so the first time right-click it and choose Open, or run:

$ xattr -dr com.apple.quarantine /Applications/Baka-MPlayer.app

For YouTube and other online videos the bundled yt-dlp is used, or your own (e.g. brew install yt-dlp).

Compilation

Don't see a package for your flavor of linux? That's okay, compiling is easy! Both X11 and Wayland are supported.

First, install the dependencies. On Debian/Ubuntu (24.04 or newer):

$ sudo apt install cmake g++ pkgconf libmpv-dev libx11-dev libgl-dev \
    qt6-base-dev qt6-svg-dev qt6-tools-dev qt6-tools-dev-tools qt6-l10n-tools yt-dlp

On Fedora:

$ sudo dnf install cmake gcc-c++ pkgconf mpv-libs-devel libX11-devel \
    qt6-qtbase-devel qt6-qtsvg-devel qt6-qttools-devel yt-dlp

On Arch Linux:

$ sudo pacman -S cmake mpv qt6-base qt6-svg qt6-tools libx11 yt-dlp

Then run the following commands:

$ git clone https://github.com/u8sand/Baka-MPlayer.git
$ cd Baka-MPlayer
$ cmake -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build
$ sudo cmake --install build
